# 26 - 信用スコアシミュレータ

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: credit-score-simulator

## 概要
支払い履歴・使用率・口座年齢などを入力し、FICOスコア式で信用スコア（300〜850）を推算するシミュレータ。各要素を変えた場合の予測スコアも即時表示。

## 機能
- 5つのスライダー入力（支払い履歴/使用率/口座年齢/口座数/照会回数）
- FICOライクな重み付き計算（各ファクターの重みを明示）
- カラーゲージで5段階評価（Poor〜Exceptional）
- What-Ifシミュレーション（要素を改善した場合のスコア差分表示）
- 最もスコアを下げている要素ベースの改善ヒント
- データは外部送信なし（プライバシー注記付き）
